# Water Quality Prediction

A deep learning project built with PyTorch to predict the Water Quality Index (WQI) and classify water quality from groundwater samples across India.

Overview
WQI Prediction         | Regression | Continuous WQI value
Quality Classification | Rule-based | Excellent / Good / Poor / Very Poor / Unsuitable
